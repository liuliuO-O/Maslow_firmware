# Maslow firmware backups

After each project change, save a new version under `D:\MaslowDev\backups\Maslow_firmware`. Name the backup with the local date and time (Asia/Shanghai, `YYYYMMDD-HHMMSS`) and a short description. Include a source snapshot, the compiled firmware when available, and a note with the changes, verification results, and SHA-256 checksums. Keep earlier versions under their original names.
